> This is a GitHub README animation proof of concept. The SVG contains its own raster background, so this image needs only `assets/chapter-1.svg` to render. `assets/background.png` is the original source artwork.

The Python circle has a slow idle rotation, pulsing gold glow and small particles. Downloading and opening `assets/chapter-1.svg` as a document also enables its stronger glow, faster rotation and extra ring on hover. In a GitHub README, the SVG is embedded as an image; browsers disable interaction with elements inside images, so the per-spell hover effect will not activate there. The idle animation still needs a live GitHub check. The labels remain visible if animation is unavailable.
